Interaction contract: Save on an empty worklist creates .xenon/worklist.md with its heading. In-tab Add opens an inline editor and focuses it every time. Quick capture uses a separate popover and focuses its field on every open, including reopen. Success notices dismiss after four seconds or on click; Undo remains in the tab footer.

Inspectable values and framework contract

One Light palette approximated: toolbar 44px, tab 36px, icon hit 30px, light chrome and cyan selection accent. Inline editor max width 770px; minimum input height 78px. Success notice lasts 4s. Reduced motion: no animation. Native implementation should use a shared focus-on-mount text input, dismissible timed notice, and explicit empty-file Save semantics. This HTML proves the proposed interaction, not GPUI focus behavior.
