Interaction and format values

Title ≤80 user-perceived characters; each point ≤100. The canvas has no horizontal separators. Tab increases the current point's depth at any caret position; Shift-Tab decreases it. Backspace at the start outdents a nested point, or merges a top-level point into the previous point. At the first point, it removes that point and returns to the title. Enter or ↓ on the title moves into the first point (creating it if needed), never another title. ↑ on the first point returns to the title. Enter on a point splits at the caret into a peer point. Xenon writes two-space-indented Markdown bullets; the user never types markers.
